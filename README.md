# 🎯 FaceRecognition System

A powerful face recognition system using cutting-edge techniques like **KNN**, **PCA**, and **CNN** to detect, recognize, and analyze human faces. Built with robust libraries such as **OpenCV**, **NumPy**, **TensorFlow**, **Scikit-learn**, and **Keras**.

>  📸 Image-based recognition | 🧠 Deep learning powered

## 🚀 Installation

```bash
git clone https://github.com/your-username/FaceRecognition.git
cd FaceRecognition
python -m venv env
source env/bin/activate  # or env\Scripts\activate on Windows
pip install -r requirements.txt
```

## ✨ Features
🔍 Face Detection from images and webcam

🧠 Deep Learning Models: CNN, PCA, KNN

🕵️‍♂️ Real-time Recognition

🧪 Easy to Train & Extend

## 🛠️ Usage

```bash
python train_model.py
python real_time_recognition.py
```

## 📦 Dependencies
